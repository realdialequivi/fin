# Acronyms Glossary

Terms used across the FPI Fin demo and the broader FPI / advisory world.

| Acronym | Expansion | Brief definition |
|---|---|---|
| FPI | Flexible Plan Investments | Independent registered investment advisor and TAMP, founded 1981. |
| TAMP | Turnkey Asset Management Program | Outsourced platform that handles portfolio management, trading and reporting for advisors. |
| RIA | Registered Investment Adviser | Firm registered with the SEC or a state regulator to provide investment advice for a fee. |
| SMA | Separately Managed Account | Individual portfolio of securities owned directly by the client and managed by a professional. |
| ETF | Exchange-Traded Fund | Pooled investment vehicle that trades on an exchange like a stock. |
| AUM | Assets Under Management | Total market value of client assets a firm manages. |
| IRA | Individual Retirement Account | US tax-advantaged retirement account. |
| VA | Variable Annuity | Insurance contract with sub-accounts that can be actively managed. |
| DAF | Donor-Advised Fund | Charitable giving account that the donor recommends grants from. |
| SDBA | Self-Directed Brokerage Account | Brokerage window inside a 401(k) plan that lets the participant pick investments. |
| 401(k) | Section 401(k) Plan | US employer-sponsored, tax-deferred retirement savings plan. |
| ESG | Environmental, Social, Governance | Investment screen based on sustainability and ethical criteria. |
| QFC | Qualified Financial Contract | US bankruptcy-code term covering swaps, repos and similar contracts. |
| SSN | Social Security Number | 9-digit US taxpayer identifier; used in the demo as the client lookup key. |
| OnTarget | OnTarget Monitoring | FPI's proprietary client-level performance tracking against a personalized goal. |
| NAV | Net Asset Value | Per-share value of a fund's assets minus liabilities. |
| S&P 500 | Standard & Poor's 500 | Index of 500 large-cap US public companies. |
| FDIC | Federal Deposit Insurance Corporation | US agency insuring bank deposits. |
| SEC | Securities and Exchange Commission | US federal regulator of securities markets and advisers. |
| ADV | Form ADV | Uniform disclosure document RIAs file with the SEC. |
| CRS | Form CRS (Client Relationship Summary) | Plain-language disclosure given to retail clients. |
| CDT | Certificado de Depósito a Término | Spanish for "time deposit certificate"; appears as a legacy label in the demo dataset, cross-referenced to a US CD (Certificate of Deposit). |
| PQR | Peticiones, Quejas, Reclamos | Spanish-language framework for customer requests/complaints; mapped to the demo's `/pqr` endpoint. |
| KYC | Know Your Customer | Regulatory process to verify a client's identity. |
| AML | Anti-Money Laundering | Set of regulations to detect and prevent money laundering. |
| API | Application Programming Interface | HTTP endpoints that Fin calls as tools. |
| UI | User Interface | The visible front-end of the demo. |
